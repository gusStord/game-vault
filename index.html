Conecte seu vault

  1. Crie um projeto em supabase.com.
  2. Execute o arquivo schema.sql no SQL Editor do projeto novo.
  3. Copie a URL e a chave pública anon em Project Settings → API (ou Data API / API Keys).
  4. Preencha SUPABASE_URL e SUPABASE_ANON_KEY no início deste HTML e publique novamente.

Sem as credenciais, você pode explorar uma demonstração em memória. As alterações são perdidas ao recarregar e não são enviadas ao Supabase.

As policies do exemplo permitem que qualquer visitante altere toda a biblioteca. Use apenas para estudo. Nunca coloque uma chave service_role ou secret no HTML.
